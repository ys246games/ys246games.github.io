07 / Developed Solo

Unity Technical Experiments

A collection of Unity experiments in lighting, mobile UI rendering, physics simulation, and view-dependent effects.

Experiment A

HDRP Atmospheric Dungeon Lighting

Used volumetric lighting, emissive materials, and post-processing in Unity HDRP to create a cinematic dungeon atmosphere.

Experiment B

Mobile-Optimized UI Background Blur

Reuses cached blur textures across multiple UI layers to reduce repeated blur passes on mobile.

Experiment C

Physics-Based Dice with Controlled Outcomes

Simulates each throw with rigidbody physics while letting the game specify the final face. The dice still roll and collide naturally.

Experiment D

View-Dependent Holographic Card Effect

Simulates holographic foil with highlights and color shifts that change with the camera angle.
